==================================================
CORE PRODUCT PRINCIPLE
==================================================

Treat the system as three distinct layers:

1. GEMINI
   Classification assistant / data-entry accelerator.

2. USER
   Final authority over garment attributes and cultural context.

3. AMODKA STYLING INTELLIGENCE
   The actual stylist responsible for deciding what should be worn together, for what occasion, in what context.

Gemini classification must therefore NOT be a prerequisite for recommendation correctness.

Define and audit the following acceptance principle:

"Gemini-Independent Styling"

If a user manually enters or corrects the complete recommendation-critical semantics of a garment, Amodka must be capable of using those semantics to produce an appropriate outfit without depending on Gemini's original classification.

Do not implement this yet. Determine whether the current architecture can support it and what must change.
