6. GOLD-STANDARD BENCHMARK V2 — CORE DESIGN

The fundamental unit of Benchmark v2 should be a:

COMPETITIVE OUTFIT SET

A competitive outfit set contains multiple outfits that are all technically viable but differ meaningfully in stylistic quality.

The objective is NOT merely:

"Can the engine generate something acceptable?"

The objective is:

"Can the engine correctly rank the best viable option above its competitors?"

7. REQUIRED COMPETITIVE SET STRUCTURE

Create at least:

30 competitive ranking scenarios

Each scenario should contain:

Minimum

3 viable competing outfits.

Preferred

4–6 viable competing outfits.

The candidates should be sufficiently different that meaningful ranking decisions are required.

Do NOT artificially construct candidates that are obviously terrible.

11. EXTERNAL EVALUATION MUST HAPPEN BEFORE LOOKING AT INTERNAL RANKING

This is critical.

For every competitive set:

Step 1

Generate all viable candidates.

Step 2

Evaluate each candidate externally using the independent 0–100 stylistic rubric.

Step 3

Rank candidates by external quality.

Only AFTER this:

Step 4

Inspect AuraCloset's internal ranking.

This prevents evaluator bias.

Do not decide what the "best" outfit is after seeing AuraCloset's score.

13. NEW PRIMARY METRIC — TOP-1 SELECTION ACCURACY

For every competitive scenario:

Determine the externally highest-quality viable outfit.

Then ask:

Did AuraCloset rank that outfit #1?

Calculate:

Top-1 Accuracy = scenarios where AuraCloset's #1 = external #1 / total competitive scenarios

This is now one of the most important AuraCloset recommendation metrics.

14. NEW SECONDARY METRIC — TOP-3 CAPTURE

Determine whether the externally best outfit appears in AuraCloset's top 3.

Calculate:

Top-3 Capture Rate

This tells us whether the engine is at least discovering the right answer even when it fails to place it first.

15. NEW METRIC — PAIRWISE RANKING ACCURACY

For every pairwise comparison:

Determine whether AuraCloset correctly ranks the externally superior outfit above the inferior one.

Calculate:

Pairwise Accuracy

This is especially useful for diagnosing ranking reversals.

16. NEW METRIC — RANKING REGRET

For every competitive set:

Calculate the difference between:

External quality of best available outfit

and

External quality of AuraCloset's #1.

Call this:

Recommendation Regret

Example:

External best = 88

AuraCloset #1 = 76

Regret = 12 points.

Lower is better.

Also report:

mean regret;
median regret;
maximum regret.
17. NEW METRIC — RANK CORRELATION

Where enough candidates exist, calculate whether AuraCloset's internal ranking broadly agrees with external ranking.

Use an appropriate rank-correlation measure if available.

If the sample size is insufficient for a meaningful statistical interpretation, report the limitation rather than pretending the result is statistically robust.

23. IDENTIFY RANKING FAILURE CLASSES

Every significant ranking failure must be classified as:

1. Candidate-generation failure

Best outfit never reached scoring.

2. Hard-constraint failure

A valid outfit was incorrectly rejected.

3. Scoring failure

The best candidate was scored incorrectly.

4. Weighting failure

The correct signals exist but one is over/under-weighted.

5. Double-counting

The same quality is rewarded multiple times.

6. Missing relationship

The engine lacks the concept entirely.

7. Personalisation conflict

The engine follows generic quality over the user's preferences.

8. Context conflict

The engine misinterprets occasion/weather/mood.

9. Data limitation

Required information isn't available.

10. Potential LLM/visual-judgement problem

The failure genuinely requires nuanced visual or semantic interpretation beyond the available deterministic signals.
