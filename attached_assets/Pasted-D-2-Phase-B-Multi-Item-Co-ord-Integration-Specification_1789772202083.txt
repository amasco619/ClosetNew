D.2 Phase B — Multi-Item / Co-ord Integration Specification
Objective

Produce a read-only implementation specification for integrating multi-item/co-ordinated garment detection into Amodka's existing wardrobe upload/classification pipeline.

Do not implement anything.

Phase A is complete and production-approved. The production database now contains the approved garment_groups and garment_group_members infrastructure, including RLS, ownership constraints, lifecycle handling, atomic group creation, and least-privilege ACLs.

The purpose of this task is to determine exactly how Phase B should integrate with the existing production architecture while preserving all existing behaviour.
