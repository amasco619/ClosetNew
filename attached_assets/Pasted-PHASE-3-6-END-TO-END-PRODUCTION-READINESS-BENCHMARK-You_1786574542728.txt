14. CANDIDATE-GENERATION ANALYSIS

For every scenario, record:

number of wardrobe items;
number of raw candidate combinations if available;
number surviving hard gates;
number surviving contextual filters;
number entering scoring;
number finally ranked.

This is important.

A recommendation can fail because:

A

The best outfit was never generated.

or:

B

It was generated but filtered incorrectly.

or:

C

It survived but was ranked incorrectly.

These are fundamentally different problems.

15. CLASSIFY EVERY SIGNIFICANT FAILURE

Use this taxonomy:

CG — Candidate generation

The right outfit never existed in the candidate pool.

HG — Hard gate

A valid outfit was incorrectly rejected.

FB — Fallback

Fallback activated incorrectly or failed to find a sensible result.

SC — Scoring

Correct candidate existed but scored incorrectly.

RK — Ranking

Scoring was broadly reasonable but ranking order was wrong.

CT — Context

Weather/occasion/formality was mishandled.

PE — Personalisation

User preferences/profile were insufficiently reflected.

FR — Freshness

Wear history/repetition behaviour was inappropriate.

SQ — Semantic quality

The deterministic representation cannot capture the relevant quality.

AI — Potential AI-suitable

The failure requires nuanced visual/semantic judgement not represented in current structured data.

16. IMPORTANT — DISTINGUISH PRODUCTION FAILURE FROM BENCHMARK FAILURE

If the production pipeline chooses an outfit that was externally rated lower than another candidate, do not automatically call it a production defect.

First determine:

Was the superior outfit generated?
Was it eligible?
Was it filtered?
Was it scored?
Was it ranked?
Was the ranking difference meaningful?
Was the external difference within evaluator noise?

Only then classify the failure.

32. RECOMMENDED INTERPRETATION

Classify the final system as:

🟢 PRODUCTION READY

The full pipeline reliably produces useful recommendations with no material unresolved safety/context failures and no unacceptable quality tail.

🟡 PRODUCTION READY WITH MONITORING

The system is usable but has known, bounded quality limitations that can be monitored and improved post-launch.

🟠 NOT YET PRODUCTION READY

The engine is promising but has material recommendation failures requiring another targeted calibration phase.

🔴 NO-GO

Material candidate-generation, hard-constraint, runtime or recommendation-quality failures remain.
