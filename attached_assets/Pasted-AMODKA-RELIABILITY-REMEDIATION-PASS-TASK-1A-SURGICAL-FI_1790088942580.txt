==================================================

- preserve local image protection
- preserve guest/local behavior
- preserve successful authenticated upload behavior

- add operation records
- add an outbox
- add idempotency
- add replay
- change database schema
- change IDs
- change B0.3/B1/B5/B6 architecture
- redesign persistence

A. authenticated + upload source available + upload succeeds
B. authenticated + upload source null
C. authenticated + upload throws
D. guest/local + upload source null
E. mixed cloud/local outcomes
F. retry after local-only outcome

The test MUST fail if an authenticated null-upload outcome is represented as durable success.
