    frames, ms, paths, status codes) on any card in release:

      "Connection paused" + "Tap to try again", neutral treatment.
    - Refusal (422 content_guardrail): keep the existing "We couldn't

    - Unexpected error: "Something went wrong" + "Tap to try again".
E2. Replace the full-card red overlay on transient failures with the 
    neutral studio surface, a small muted icon and the copy above,

    a transient failure state. It reuses the serial queue (no parallel 
    bursts, respects aiLimiter 10/min and the PhotoRoom quota) and 
    does not re-run PhotoRoom where a cutout already succeeded.
E4. No new dependency. If @react-native-community/netinfo is already 
    installed, show a quiet "You appear to be offline" line above the 
    grid; otherwise skip. Never auto-retry in a loop.

    another try".
E6. Tests: transient error maps to "Connection paused"; 422 maps to the
