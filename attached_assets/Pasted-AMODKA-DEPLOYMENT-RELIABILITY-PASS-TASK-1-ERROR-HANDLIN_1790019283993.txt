--------------------------------------------------
1. STARTUP DEADLINE AND SPLASH RECOVERY
--------------------------------------------------

Add a bounded startup mechanism around the EXISTING startup process.

Requirements:

- Do not redesign startup.
- Do not replace AppContext architecture.
- Do not remove existing initialization.
- Do not change authentication semantics.
- Do not change profile/wardrobe hydration semantics.

The startup system must:

1. Prevent indefinite waiting.
2. Have a clearly defined maximum startup wait.
3. Ensure there is always an attempt to dismiss the native splash.
4. Transition to an explicit recovery/degraded state if initialization cannot complete.
5. Allow the user to retry initialization.
6. Allow safe continuation with existing cached/local data where the current application already supports that.
7. Never fabricate successful remote synchronization.
8. Report the startup failure category through the new redacting reporter.

Use the existing Amodka visual language.

Do NOT perform a visual redesign.

Test at minimum:

- successful startup
- font load failure
- font never resolving
- AsyncStorage never resolving
- session never resolving
- DB hydration never resolving
- entitlement never resolving
- signed URL never resolving
- startup timeout
- retry succeeds
- retry fails
- splash hide failure

- error category

The adapter MUST NOT record:

- passwords

- signed URLs
- image bytes
- base64 image content
- wardrobe images
- raw external API payloads
- email addresses
- precise location
- full profile objects
- secrets
- credentials
- database connection information

Use allowlisted metadata.

DO NOT recursively serialize arbitrary request, response, error, context, or user objects.

If an unknown Error object contains unsafe information, report only:

- safe error type/name where appropriate
- stable internal category
- safe message chosen by the application
- stack only if verified to contain no sensitive payload

When uncertain, omit the field.
