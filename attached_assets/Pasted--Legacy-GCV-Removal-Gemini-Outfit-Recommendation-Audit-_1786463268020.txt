# Legacy GCV Removal + Gemini Outfit Recommendation Audit

Act as an **elite mobile application engineer, AI/LLM integration architect, prompt optimization engineer, and fashion recommendation systems specialist**.

I need you to perform this task in **two strictly separated phases**.

The objective is to remove obsolete legacy Google Cloud Vision (GCV) code safely, then rigorously evaluate the Gemini-powered outfit recommendation logic to determine whether it has everything required to produce the **best possible outfit combination for each user**.

---

# PHASE 1 — Remove Legacy GCV Code

There is legacy **Google Cloud Vision (GCV)** code remaining in the application that is no longer required.

Your first responsibility is to **identify and safely remove the obsolete GCV implementation and all genuinely unused code associated with it**.

### Before making changes

First inspect the codebase and determine:

* Where GCV is currently referenced.
* Which files, functions, imports, dependencies, environment variables, API routes, services, utilities, configuration, comments, and documentation exist solely because of GCV.
* Whether any apparently GCV-related code is still required elsewhere.
* Whether removing GCV could break another part of the application.
* Whether any Gemini functionality currently depends on GCV-derived data.

Do not assume that code is obsolete merely because it appears old. Verify its actual usage.

### Then perform the cleanup

Remove:

* obsolete GCV imports
* GCV API calls
* GCV services/utilities
* unused GCV-related functions
* obsolete API routes/endpoints
* unused dependencies
* obsolete configuration/environment variables where appropriate
* dead code that existed solely to support GCV
* outdated comments/documentation relating to the removed implementation

### Important constraint

**Do not redesign the Gemini recommendation system during Phase 1.**

Do not alter Gemini prompts, Gemini API calls, recommendation logic, outfit-ranking logic, recommendation schemas, or other unrelated functionality unless a change is strictly necessary to remove a direct GCV dependency.

The goal of Phase 1 is:

> **Cleanly remove the obsolete GCV implementation without unnecessarily changing the application's existing behaviour.**

After making the Phase 1 changes, verify that:

* the application still builds/runs
* there are no remaining unintended GCV references
* no required functionality has been broken
* there are no obvious dead imports/dependencies resulting from the cleanup
* the Gemini functionality remains intact
