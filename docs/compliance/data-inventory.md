# Amodka — Complete Data Inventory

**Phase 5B | Date:** 2026-08-14  
**Status:** Verified against source code. Every claim traced to actual implementation.

---

## Scope

This inventory covers every category of data Amodka collects, derives, stores, transmits, logs, or sends to third parties. It was produced by auditing the React Native client, Express backend, Supabase schema, storage, Gemini, PhotoRoom, weather provider, authentication, telemetry, local storage, and server logs.

## What Is Not Collected

- Microphone / camera roll (not in use — camera only accessed on-demand per item)
- Contacts
- Push notification tokens (no notification infrastructure present)
- Crash/ANR reports (no Sentry, Bugsnag, Firebase Crashlytics, or equivalent)
- Analytics events via any SDK (no Amplitude, Mixpanel, Firebase Analytics, etc.)
- Advertising identifiers (IDFA / GAID)
- Precise biometric data
