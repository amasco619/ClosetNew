# Runner Fixture Catalog — INTERNAL, Track C only

**Phase:** 5C.3 Track B  
**Version:** 1.0  
**Date:** 2026-08-19  
**Audience:** Track C runner / benchmark author. NOT for reviewer distribution  

This is the fully typed runner catalog: every candidate item with the implementation
attributes (occasion tags, numeric formality, warmth band) the Track C runner needs to
construct wardrobe items. It must stay row-for-row identical to the reviewer-facing
`../fixtures.md` on ID, category, sub-type, pattern, scale, fabric, and colour — the
validator (`scripts/validate-benchmark-fixtures.mjs`) enforces this.

**The reviewer must never see this file.** The occasion tags, formality, and warmth
values here are author-assigned implementation inputs, not truth; the reviewer's
independent judgements on these dimensions are exactly what the benchmark measures.

All items are women's garments.

## Fingerprint convention

An outfit's fingerprint is its component IDs sorted lexicographically and joined with
commas, e.g. `F01,F07,F11,F14`. Fingerprints are computed from this catalog only; the
Track C runner must reject any case fingerprint that references an ID not present here.
