> **Reviewer note:** For each case you will receive an image (or a detailed text

> `reviewer-instructions.md`. Record what the garment *actually is* — its type, fabric,
> pattern, visual weight, appropriate occasions, formality, set membership, and cultural

garments and accessories. This is intentional: Amodka v1 is a women's fashion product.
