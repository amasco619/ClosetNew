# GU Taxonomy Analysis — INTERNAL, post-lock only

**Audience:** Benchmark author / Track C evaluation. NOT for reviewer distribution.  
**Purpose:** Provisional mapping of each GU garment to the current Amodka taxonomy, and
suspected representation gaps. These are developer hypotheses, not gold truth. This file
is the **separate developer-authored mapping artifact**, keyed by case ID: after the
reviewer's labels are locked, it is finalized against the locked labels and used for
Track C gap analysis. Signed label files are never modified to carry this analysis.

> If a reviewer's gold classification contradicts a mapping below, the gold label wins;
> the mapping is corrected and the disagreement recorded as a finding.
