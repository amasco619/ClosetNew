# Fixture Catalog — African/Nigerian Fashion Benchmark v1

**Phase:** 5C.3 Track B  
**Version:** 1.0  
**Date:** 2026-08-19  
**Audience:** Reviewer package (neutral descriptive catalog)  

This catalog describes every candidate item used in the outfit-ranking (OR), occasion
(OC), and weather (WX) cases. Each item has exactly one immutable ID and one factual
description. Case files reference items by ID only — no case may redefine, recolour, or
repurpose an item. Outfit fingerprints are the sorted, comma-separated item IDs of an
outfit's components.

Items are described factually (what the garment is). All judgements about occasion
suitability, formality, and weather appropriateness are yours to make — nothing in this
catalog pre-assigns them.

All items are women's garments.

## Fingerprint convention

An outfit's fingerprint is its component IDs sorted lexicographically and joined with
commas, e.g. `F01,F07,F11,F14`. Fingerprints identify outfits stably across documents.
