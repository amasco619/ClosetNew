Treat the Track C v3.7 baseline as two related but distinct measurements: fixed benchmark candidates ranked with unchanged production item/profile plus combination scores, and exact benchmark fingerprints found in the unchanged full generator. Never present a fixed candidate as generated unless its exact fingerprint appeared in the production pool.

The frozen baseline recommendation is **C — material recommendation gaps require remediation before Nigerian/African launch**. Future Nigeria-specific changes require a separate authorized hypothesis → controlled experiment → Track C comparison → unchanged existing-regression comparison → approval cycle.

**Why:** The frozen benchmark protocol did not define a complete candidate-to-generator mapping, while production weather behavior exists in generation rather than fixed combination scoring. Combining the measures would overstate support. The baseline found material weather, cultural-taxonomy, guardrail, matching-set, and diaspora gaps alongside strong top-three and focused Ankara results.

**How to apply:** Keep v3.7 and the frozen benchmark unchanged. Use the sealed baseline artifacts as the comparison point, report both measurements separately, and require any future experiment to improve Nigerian/African evidence without degrading the existing v3.7 golden regression suite.
